# Job Tracker

A full-stack job application tracking platform that helps users organize, monitor, and manage their job search efficiently. Users can securely store applications, track interview progress, and manage their job-hunting workflow through an intuitive dashboard.

## 🚀 Live Demo

- **Frontend:** https://job-tracker-mocha-eight.vercel.app/

## 📖 Project Information

Job Tracker is a MERN stack web application designed to simplify the job application process. It provides a centralized platform where users can create, update, and manage job applications while tracking each application's status throughout the recruitment process.

### ✨ Key Features

- 🔐 Secure JWT Authentication
- 👤 User Registration & Login
- 📋 Create, Update & Delete Job Applications
- 📊 Track application status (Applied, Interview, Offer, Rejected)
- 🔍 Search and filter job applications
- 📱 Responsive UI
- ☁️ MongoDB Atlas cloud database
- 🚀 Deployed using Vercel & Render

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt

### Deployment
- Frontend: Vercel
- Backend: Render
